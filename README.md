## ⚙️ Requisitos

- Compilador con soporte para **C++17** o superior (`g++` 9+, `clang++` 10+ o MSVC 2019+)
- Opcional: `make` o `cmake` para automatizar la compilación

Verifica tu versión:

```bash
g++ --version
```

## 🚀 Cómo compilar y ejecutar

Clona el repositorio:

```bash
git clone https://github.com/TU_USUARIO/TU_REPO.git
cd TU_REPO
```

Compila y ejecuta cualquier ejercicio:

```bash
g++ -std=c++17 -Wall -Wextra -O2 01-basicos/hola_mundo.cpp -o hola_mundo
./hola_mundo
```

En Windows (PowerShell):

```powershell
g++ -std=c++17 -Wall -Wextra -O2 01-basicos\hola_mundo.cpp -o hola_mundo.exe
.\hola_mundo.exe
```

## 📝 Convenciones

- Un archivo `.cpp` por ejercicio, con nombre en `snake_case`.
- Cada archivo inicia con un comentario con el enunciado y, si aplica, el enlace al problema original.
- Se incluyen casos de prueba de ejemplo en comentarios o en un archivo `.in` / `.out` junto al código.

Ejemplo de encabezado:

```cpp
/*
 * Problema: Suma de dos números
 * Fuente:   (enlace o libro)
 * Dificultad: Fácil
 * Complejidad: O(1)
 */
```
